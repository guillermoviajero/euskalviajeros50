# Euskal Viajeros +50 (Bidelagunak)

> **Comunidad de viajeros y viajeras mayores de 50 años en Euskal Herria para compartir la experiencia del viaje y el apoyo mutuo.**

---

## 🌍 Sobre el Proyecto

**Euskal Viajeros +50** es una iniciativa sin ánimo de lucro diseñada para personas de 50 años en adelante de Bizkaia, Gipuzkoa, Araba, Nafarroa e Iparralde que desean viajar en grupo, evitar viajar en soledad y disfrutar de ritmos sosegados, enriquecedores y seguros.

### Pilares Fundamentales:
1. **🤝 Apoyo Mutuo:** Empatía, respeto a los diferentes ritmos y cuidado personal durante todo el trayecto.
2. **☕ Reuniones Presenciales Previas:** Encuentros en cafeterías y salas céntricas (Bilbao, Donostia, Gasteiz, Iruña) antes de cada viaje para ponernos cara, debatir la ruta y generar un ambiente de total confianza y amistad.
3. **👥 Grupos Reducidos:** Entre 8 y 14 personas para una convivencia ágil y humana.
4. **🧭 Autonomía y Transparencia:** Sin comisiones ni intermediarios comerciales; cada miembro gestiona sus reservas de común acuerdo.

## 💻 Visualización y Estructura Web

El sitio web está implementado en `index.html` con un diseño moderno, responsive y accesible:
- **Diseño pensado para el público +50:** Tipografías legibles (*Plus Jakarta Sans* y *Outfit*), generoso contraste, botón de accesibilidad para ampliar tamaño de letra (A / A+), navegación clara e intuitiva.
- **Secciones:**
  - *Inicio / Hero*: Presentación del espíritu del grupo y compromisos.
  - *Nuestra Filosofía*: Valores de apoyo, tranquilidad y respeto.
  - *Cómo Funciona*: El ciclo en 5 pasos (Sondeo, Reuniones Presenciales, Reservas, Convivencia y Encuentro Post-Viaje).
  - *Reuniones Presenciales*: Información de convocatorias por provincia (Bizkaia, Gipuzkoa, Araba, Nafarroa).
  - *Destinos en Preparación*: Ideas de viajes serenos (Toscana, Azores, Pueblos Blancos).
  - *Dudas Frecuentes (FAQ)*: Acordeón interactivo con respuestas transparentes.
  - *Formulario de Contacto*: Registro sencillo para asistir a un primer café informativo.

## 🚀 Cómo Publicar la Web en GitHub Pages

Para que la web esté disponible públicamente en internet de forma gratuita con tu repositorio:

1. Ve a tu repositorio en GitHub: [https://github.com/guillermoviajero/euskalviajeros50](https://github.com/guillermoviajero/euskalviajeros50)
2. Haz clic en la pestaña **Settings** (Configuración).
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección **Build and deployment** / **Source**:
   - Selecciona **Deploy from a branch**.
   - En **Branch**, elige `main` y la carpeta `/(root)`.
   - Haz clic en **Save**.
5. ¡Listo! En un par de minutos tu web estará publicada en:
   **`https://guillermoviajero.github.io/euskalviajeros50/`**

## 🖥️ Cómo Probar la Web en Local

Puedes abrir el archivo `index.html` directamente con tu navegador favorito (doble clic) o ejecutar un servidor local:

```bash
# Con Python
python -m http.server 8080

# O con npx
npx serve
```
Y abrir `http://localhost:8080`.
